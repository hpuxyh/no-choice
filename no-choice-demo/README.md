# 不做选择 Web

不做选择的 React + Vite 网页原型，用来验证“输入问题 -> 补充条件 -> 生成候选 -> 滑卡拍板”的核心体验。

## 功能

- 预设场景：今晚吃什么、送什么礼物、要不要辞职、跟谁约会。
- 条件标签：记录距离、价格、风险、聊天氛围等偏好。
- 自动推荐与手动候选：既可以让系统生成，也可以自己添加候选。
- 滑卡决策：滑动比较候选，滑到底时系统兜底拍板。
- 结果分享：支持复制或系统分享最终结论。

## Demo 边界

- 大模型推荐先用本地规则和候选池模拟。
- 推荐理由使用本地模板库，后续可在 `src/decisionEngine.js` 里替换为后端 AI 接口。
- 餐厅和地点候选仍是策略/类别示例，未接真实位置、POI、营业时间和距离。
- 图片暂时使用固定远程素材，不参与推荐逻辑。
