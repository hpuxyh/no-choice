# 不做选择 Web

不做选择的 React + Vite 网页原型，用来验证“输入问题 -> 补充条件 -> 生成候选 -> 滑卡拍板”的核心体验。当前重点是今晚吃什么、周末去哪、送什么礼物和通用拍板四个模块。

## 功能

- 场景模块：吃饭、周末、礼物、通用四套文案、条件和候选池。
- 条件标签：按模块记录位置、预算、天气、关系分寸、风险等偏好。
- 手机定位：吃饭和周末模块可点击获取当前位置，并尝试读取附近 POI。
- 自动推荐与手动候选：既可以按条件生成，也可以自己添加候选。
- 滑卡决策：滑动比较候选，滑到底时系统兜底拍板。
- 结果分享：支持复制或系统分享最终结论。

## POI 配置

Cloudflare Pages 版会把 `/api/poi` 交给 `public/_worker.js` 处理。真实 POI 需要在 Cloudflare Pages 环境变量里设置：

```text
AMAP_WEB_SERVICE_KEY=你的高德 Web 服务 API Key
```

前端可选配置：

```text
VITE_POI_ENDPOINT=/api/poi
```

不要把真实地图 Key 写进前端 `.env`，否则会被打包进浏览器代码。

## Demo 边界

- 大模型推荐先用本地规则和候选池模拟。
- 推荐理由使用本地模板库，后续可在 `src/decisionEngine.js` 里替换为后端 AI 接口。
- 未配置地图 Key 时，餐厅和地点候选仍是策略/类别示例；配置后会优先使用附近 POI。
- 礼物候选仍是本地规则示例，未接商品搜索、库存、配送和价格。
- 图片暂时使用固定远程素材，不参与推荐逻辑；后续真实地点/商品应优先使用数据源返回的图片。
